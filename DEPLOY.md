# Automated Deployment

## ✅ Deployed Successfully
**Live URL**: https://scheme-explainer-frontend.vercel.app

## 🚀 Auto-Deploy Setup

Go to Vercel Dashboard and connect GitHub:
1. https://vercel.com/rmr2024s-projects/scheme-explainer-frontend/settings/git
2. Connect repository: `Meghana-Chakravarthi/ai-scheme-explainer`
3. Set Root Directory: `frontend`
4. Enable auto-deployments

Every push to `main` will now auto-deploy!

## Manual Deploy
```bash
cd frontend && vercel --prod
```
